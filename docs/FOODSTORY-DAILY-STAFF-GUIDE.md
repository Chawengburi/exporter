# คู่มือพนักงาน: ดึงรายงาน FoodStory ของเมื่อวาน

ทำวันละครั้ง ใช้เวลากดจริงไม่ถึง 1 นาที ที่เหลือโปรแกรมทำเองราว 5–10 นาที

> รูปในคู่มือนี้เป็นภาพจำลอง หน้าจอจริงอาจต่างเล็กน้อย

## ทุกวัน (พนักงาน)

**ทำเมื่อไหร่ก็ได้ในวันนั้น** — โปรแกรมดึงยอดของ **เมื่อวาน** เสมอ (วันที่ปิดยอดแล้ว) ไม่ว่าจะกดตอนเช้าหรือตอนเย็น

### 1. ดับเบิลคลิกไฟล์บน Desktop

![ไฟล์ "ดึง FoodStory เมื่อวาน" บน Desktop](images/foodstory-daily/1-desktop-file.svg)

หน้าต่างสีดำ (Terminal) จะเปิดขึ้นมาพร้อมคำแนะนำ — ไม่ต้องพิมพ์อะไร

![หน้าต่าง Terminal ตอนเริ่ม](images/foodstory-daily/2-terminal-start.svg)

### 2. ยืนยันว่าไม่ใช่โปรแกรมอัตโนมัติ แล้วเข้าสู่ระบบ — ภายใน 5 นาที

หน้าต่างเบราว์เซอร์จะเปิดขึ้นมาที่หน้าเข้าสู่ระบบ FoodStory **อีเมลกับรหัสผ่านกรอกไว้ให้แล้ว**

1. ติ๊กช่อง **"ฉันไม่ใช่โปรแกรมอัตโนมัติ"** (บางครั้งขึ้นเป็น "I'm not a robot") ถ้ามีรูปให้เลือก ทำตามจนผ่าน
2. กดปุ่ม **เข้าสู่ระบบ**

![หน้าเข้าสู่ระบบ: ติ๊กช่อง แล้วกดปุ่มเข้าสู่ระบบ](images/foodstory-daily/3-captcha.svg)

### 3. ปล่อยไว้จนหน้าต่าง Terminal ขึ้นสรุป

หลังเข้าสู่ระบบ โปรแกรมจะเปิดหน้ารายงานทีละหน้าเอง **ไม่ต้องกดอะไรในเบราว์เซอร์** และอย่าปิดหน้าต่างใดระหว่างนี้
(ใช้คอมพิวเตอร์ทำงานอื่นต่อได้ แต่อย่าคลิกในหน้าต่างเบราว์เซอร์นั้น)

### 4. อ่านสรุป แล้วกดปุ่มใดก็ได้เพื่อปิดหน้าต่าง

![สรุปตอนจบ 3 แบบ](images/foodstory-daily/4-terminal-done.svg)

| ขึ้นว่า | ต้องทำอะไร |
|---|---|
| ✅ **เสร็จเรียบร้อย** | ไม่ต้องทำอะไรต่อ ปิดหน้าต่างได้เลย |
| ⚠️ **ได้บางส่วน** | ดับเบิลคลิกไฟล์เดิมอีกครั้ง แล้วกด captcha ใหม่ — รายงานที่ได้แล้วจะไม่หาย · ถ้ารอบที่สองยังขึ้นแบบเดิม ถ่ายรูปหน้าจอส่งให้ผู้ดูแลระบบ |
| ❌ **ไม่สำเร็จ** | ถ้าขึ้นว่า "ยังไม่ได้รายงาน" ส่วนใหญ่เพราะกดเข้าสู่ระบบไม่ทันใน 5 นาที หรืออินเทอร์เน็ตหลุด — ดับเบิลคลิกใหม่อีกครั้ง ถ้ายังไม่ได้ถ่ายรูปหน้าจอส่งให้ผู้ดูแลระบบ · ถ้าขึ้นว่า "เข้าสู่ระบบได้ แต่ไม่ได้รายงานเลย" ถ่ายรูปหน้าจอส่งให้ผู้ดูแลระบบเลย |

## คำถามที่พบบ่อย

- **ลืมกดไปวันหนึ่ง เป็นอะไรไหม** — ไม่เป็นไร โปรแกรมไม่ย้อนไปเก็บวันที่พลาด แต่ยอดของวันนั้นยังอยู่ในรายงานรายเดือนที่ผู้ดูแลระบบดึงทุกเดือน
- **กดซ้ำในวันเดียวกันได้ไหม** — ได้ ผลจะรวมกับรอบก่อนของวันนั้น รายงานที่ได้แล้วไม่หาย
- **เผลอดับเบิลคลิกสองครั้ง** — หน้าต่างที่สองจะบอกว่า "รันอยู่แล้ว" ให้ปิดหน้าต่างนั้นแล้วรอหน้าต่างแรกจนจบ
- **เผลอปิดหน้าต่างระหว่างทำงาน** — ดับเบิลคลิกใหม่ได้เลย
- **ขึ้นข้อความเกี่ยวกับ `.env`, Node.js หรือ `npm install`** — เป็นเรื่องการติดตั้ง ถ่ายรูปหน้าจอส่งให้ผู้ดูแลระบบ
- 🔴 **ไฟล์ที่ได้มีข้อมูลลูกค้าและยอดขาย** — ห้ามส่งต่อออกนอกร้าน ห้ามอัปโหลดขึ้นที่อื่น

## สำหรับผู้ดูแลระบบ

### ติดตั้งครั้งแรก (ทำครั้งเดียวต่อเครื่อง)

ไม่ผูกกับเครื่องใดเครื่องหนึ่ง — ตอนนี้ (2026-10) ติดตั้งบน Mac ของผู้ดูแลระบบ (เครื่อง dev/test ที่รัน exporter อยู่แล้ว) ·
ทำแบบเดียวกันบนเครื่องกลางเมื่อย้ายระบบ

1. ติดตั้ง Node.js **22.18 ขึ้นไป** (ผ่าน nvm, Homebrew หรือตัวติดตั้งจาก nodejs.org ก็ได้ — ไฟล์ดับเบิลคลิกหา node เองทั้ง
   `PATH`, nvm default, `/opt/homebrew/bin` และ `/usr/local/bin` ไม่ต้องตั้ง `PATH`)
2. ในโฟลเดอร์ `exporter/`: `npm install` แล้ว `npx playwright install chromium`
3. สร้าง `exporter/.env` จาก `.env.example` ใส่ `FOODSTORY_*` (อีเมล/รหัสผ่าน/สาขา) — ไฟล์นี้ห้าม commit
4. วางไฟล์บน Desktop เป็น **symlink หรือ alias** (อย่าก๊อปไฟล์ — ก๊อปแล้วจะหาโฟลเดอร์ exporter ไม่เจอ):

   ```bash
   ln -s "<ที่อยู่ repo>/exporter/launchers/foodstory-daily.command" ~/Desktop/"ดึง FoodStory เมื่อวาน.command"
   ```

   หรือใน Finder: คลิกขวาที่ `exporter/launchers/foodstory-daily.command` → Make Alias → ลาก alias ไปไว้บน Desktop
5. ลองดับเบิลคลิกเองหนึ่งรอบ ครั้งแรก macOS อาจถามสิทธิ์ให้ Terminal — กดอนุญาต

### ไฟล์ไปอยู่ที่ไหน

`exporter/data/foodstory/daily/<YYYY-MM>/<เมื่อวาน>/` (ชื่อไฟล์ `<เมื่อวาน>__<กลุ่ม>__<รายงาน>.xlsx`) และ
`exporter/data/foodstory/daily/latest` ชี้รอบล่าสุด · สรุปผลอ่านได้ที่ `_summary.txt` ในโฟลเดอร์นั้น · รายละเอียด:
[`exporter/README.md`](../exporter/README.md) และ ADR-0005/0006

### เมื่อพนักงานส่งรูปหน้าจอมา

- ⚠️/❌ ซ้ำสองรอบ: ดู `_summary.txt` ของวันนั้นว่ารายงานไหนล้มด้วยข้อความอะไร แล้วดูคู่มือ exporter
  (`.claude/skills/exporter/SKILL.md` ส่วน FoodStory)
- ข้อความเรื่อง `.env` / Node.js / `npm install`: ทำขั้นติดตั้งด้านบนให้ครบ
- ตัวไฟล์ดับเบิลคลิกคือ `exporter/launchers/foodstory-daily.command` — รัน
  `node src/index.ts export --site foodstory --report all --daily --headful` ในโฟลเดอร์ exporter แล้วสรุปเป็นภาษาไทยจาก
  `_run.json` ของโฟลเดอร์เมื่อวาน (รวมผลทุกรอบของวันนั้น — รอบนี้ล้มบางใบแต่ไฟล์จากรอบก่อนยังอยู่ ถือว่าได้แล้ว)
- ล็อกกันรันซ้อนอยู่ที่ `data/foodstory/.daily-launcher.pid` (ล็อกค้างจาก process ที่ตายแล้วถูกยึดต่อเอง) — ไม่กันรอบที่ผู้ดูแลรันเอง
  ด้วย `exporter export ...` อย่ารันพร้อมกับพนักงาน
