# อัปเดตเครื่อง Ubuntu — 2026-11-16 (หน้าเดียว)

เครื่องนี้ = เครื่อง production เครื่องเดียวที่ export + upload ทำตามทีละขั้น ถ้าอะไรไม่ตรงกับ "ควรเห็น" ให้**หยุด**แล้วส่งรูปหน้าจอให้ผู้พัฒนา (ห้ามส่งไฟล์ข้อมูล .csv/.xlsx, `.env`, `.admin-password`)

## ในการอัปเดตนี้มีอะไร
1. **รายงานใหม่ 2 ตัวของ HotelTime:** `vat-output` (ใบกำกับภาษีขาออก) และ `vat-inspection` (ภาษีแยกรายอัตรา) — เป็นรายงานตามวัน เมื่ออัปเดตแล้ว HotelTime จะมี **25** รายงานตามวัน (เดิม 23) รวม 52 รายงาน
2. **ชื่อใน Windmill เปลี่ยน** เป็นรูป `[Exporter] HotelTime (12.00) Daily` ฯลฯ เพื่อให้เรียงตามชื่อแล้วอ่านง่าย — เปลี่ยนเฉพาะชื่อที่แสดง เวลาและการทำงานเหมือนเดิม
3. **เอกสาร/ข้อความ:** FoodStory login เป็น Cloudflare Turnstile (ระบบแก้ผ่าน 2captcha เหมือนเดิม ไม่ต้องทำอะไร)

- จดเลขเวอร์ชันปัจจุบันไว้เผื่อย้อนกลับ: `cd ~/chawengburi-exporter && git rev-parse --short HEAD`
- ดู `exporter status` ไว้เทียบหลังอัปเดต (ตอนนี้ HotelTime ยังเติมวันที่ขาดอยู่ อาจขึ้น "ขาดอีก N วัน" เป็นปกติ)

## ขั้นตอน
```bash
cd ~/chawengburi-exporter && git pull && bash deploy/ubuntu/install.sh
```
ตัวติดตั้งรันซ้ำได้ปลอดภัย (ไม่ถามรหัสซ้ำ ไม่แตะ `.env`) และรัน `windmill/setup.mjs` ให้เอง **ไม่ต้องรัน setup.mjs แยก**

**ควรเห็นในผลลัพธ์:**
- `Deployed a new version of the script …` หลายบรรทัด (เป็นการเปลี่ยนชื่อ script เดิม) และ `Updated the schedule of …` — ปกติ
- `Nothing changed` ในรอบที่รันซ้ำ — ปกติ

**ห้ามเห็น (ให้หยุดทันที):** `Created the script …` หรือ `Set the schedule of …` สำหรับ script ที่เคยมีอยู่แล้ว = ถูกสร้างซ้ำ จะทำให้ดึง/อัปโหลดซ้ำสองรอบ · หรือบรรทัด `✘`
