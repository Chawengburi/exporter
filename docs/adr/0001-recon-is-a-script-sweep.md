# recon เป็นงานของสคริปต์ ไม่ใช่งานที่ AI อ่าน

2026-09-17 · เมนูของ HotelTime มี **203 ลิงก์** และ ARIA snapshot ของหน้าเดียวราคา
**~30,000 token** (วัดจากขนาดไฟล์จริงใน `pms-export/recon/captures/`) การให้ AI อ่านทุกหน้า
จึงเป็นไปไม่ได้เชิงต้นทุน · แต่ทุกรายการในเมนูเป็น `<a href>` จริง ไม่ใช่ `__doPostBack`
จึง deep-link เข้าได้ตรง ๆ · **เราจึงให้สคริปต์ Playwright กวาดทุกหน้าแบบอ่านอย่างเดียว**
เพื่อบันทึกว่าหน้าไหนมีปุ่ม `Export: MS Excel` ชื่อ control ในฟอร์มคืออะไร และมีฟิลด์บังคับไหม
แล้วจ่ายค่า **recon เชิงลึก** (AI อ่าน) เฉพาะหน้าที่เจ้าของข้อมูลเลือกแล้วเท่านั้น

**แทนที่สมมติฐานราคาใน `pms-export/specs/09-spec-recon-schema-and-codegen.md` §12**
ซึ่งคิดต้นทุนบนฐานว่า Claude เป็นคนอ่าน snapshot แล้วกรอก schema เอง · ใบ 09 ไม่ได้ผิด
ตอนเขียน แต่ตั้งอยู่บนฐานที่เปลี่ยนไปแล้ว — schema ส่วนใหญ่ควรถูกเติมด้วยเครื่อง

**ผลที่ตามมา:** การกวาดต้องอ่านอย่างเดียวเสมอ ห้ามคลิกอะไรทั้งสิ้น — หน้าผลลัพธ์บางหน้ามี
