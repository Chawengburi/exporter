# FoodStory มีรอบรายวันด้วย โดยให้พนักงานกด reCAPTCHA เองทุกวัน

2026-10-07 · สเปกต้นทางของ FoodStory (§9) และ `sites/foodstory/export.ts` ระบุว่ามีแค่รอบรายเดือน
แต่เจ้าของต้องการข้อมูลรายวันด้วย ขณะที่ login ของ FoodStory ต้องมีคนแก้ reCAPTCHA ทุกครั้ง และรัน
บน Windmill ไม่ได้ (worker เป็น container ไม่มีหน้าจอ) · **ทางที่เลือก:** เพิ่มรอบรายวันที่ดึง**เมื่อวาน**
ทั้ง 48 รายงาน ให้พนักงานเริ่มรันจาก Mac เครื่องนี้ด้วยการดับเบิลคลิกไฟล์ `.command` แล้วกด captcha
ครั้งเดียว ส่วนที่เหลือรันเอง · รอบรายเดือนยังอยู่ และทำหน้าที่เก็บการแก้ยอดย้อนหลังแบบเดียวกับ baseline

**ผลที่ตามมา:** วันที่พนักงานไม่ได้กดจะไม่มีข้อมูลรายวันของวันนั้น (เลือกดึงเมื่อวานวันเดียว ไม่ไล่เก็บ
วันที่พลาด) แต่รอบรายเดือนยังครอบคลุมวันเหล่านั้น · การลดจำนวนครั้งที่ต้องกด captcha ด้วย session
ที่เก็บไว้บนดิสก์ แยกเป็นงานทดลองต่างหาก
