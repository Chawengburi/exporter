# รอบรายวันดึงเมื่อวานทีละวัน และแยกรายงานตามวันออกจากรายงานภาพ

2026-10-13 · เดิม (2026-10-07) HotelTime ledger ดึงย้อน 3 วันถึงวันนี้ทุกวัน เป็นค่าเผื่อที่ไม่ได้วัด
(`core/order.ts` `DEFAULT_DAILY_OVERLAP_DAYS`) วันเดียวกันจึงอยู่ใน 3 ไฟล์ และไฟล์ทุกไฟล์มีวันนี้ที่ยังไม่ครบ
(รันตอนเที่ยง) · เมื่อ uploader ไม่กันไฟล์ซ้ำ ไฟล์ที่ครอบวันคร่อมกันทำให้ยอดเบิ้ล และการส่งไฟล์ดิบ (ADR-0007)
ทำให้แตกไฟล์รายวันเองไม่ได้อีกแล้ว

**ทางที่เลือก:** แบ่งรายงานเป็นสองส่วนทั้งสอง Site · **รายงานตามวัน** (ledger และยอดรวมของวันเดียว) ขอ Site
ทีละ **วันของข้อมูล** ได้ไฟล์ละวัน ไม่มีการคร่อม · รอบรายวันตอนเที่ยงดึง**เมื่อวาน** ทั้ง HotelTime และ FoodStory ·
**รายงานภาพ** (สถานะห้อง/แขก/สต็อก ข้อมูลหลัก ยอดสะสม พยากรณ์) ถ่าย ณ เวลาที่รัน ทุกครั้งเป็นฉบับใหม่ที่ระบุเวลาที่
ถ่าย ไม่แทนฉบับก่อน รองรับการดึงถี่ขึ้นภายในวันในอนาคตได้โดยไม่ต้องเปลี่ยนแนวคิด · วันแรกของเดือนและของปี
ถ่าย**ภาพปิดงวด**ของงวดที่แล้วทั้งงวดเพิ่ม เพราะภาพยอดสะสมตอนเที่ยงไม่มีภาพไหนครอบครึ่งหลังของวันสุดท้าย

**ทางที่ไม่เลือก:** ดึง 2 วันก่อน (เก็บการแก้ช่วงแรกได้มากกว่า แต่ข้อมูลช้า 2 วัน และยังต้องมี baseline อยู่ดี) ·
คงช่วง 3 วันแล้วให้ uploader แทนไฟล์ตามช่วง (ต้องรอ uploader และไฟล์ยังมีวันนี้ที่ไม่ครบ)

**ผลที่ตามมา:** รอบรายวันเห็นสถานะของเมื่อวาน ณ เที่ยงวันนี้เท่านั้น วัดได้ว่า 10 จาก 111 คู่ (รายงาน, วัน) เปลี่ยน
ระหว่างวันถัดไปกับอีกวันถัดไป จึงต้องมี **baseline** ซึ่งออกเป็นไฟล์ละวันของข้อมูลเหมือนกัน ใช้ key รายงาน +
วันของข้อมูลชุดเดียวทั้งระบบ · รายงานยกเลิกของ HotelTime ตัดวันตาม UTC ไฟล์ของวันหนึ่งจึงมีแถวที่เวลาไทยเป็น
เช้ามืดวันถัดไปได้ และรอบต้องรันหลัง 07:00 เวลาไทย (เที่ยงวันผ่านเงื่อนไขนี้) · ADR-0003 ยังใช้ได้: รายงานปฏิบัติการ
รายวันเป็นรายงานภาพ ดึงย้อนหลังไม่ได้ · โฟลเดอร์รายวันยังจัดตาม**วันของข้อมูล**ตาม ADR-0005: โฟลเดอร์ของวัน D เก็บรายงานตามวันของ D
(ดึงวัน D+1) และภาพที่ถ่ายในวัน D — `_run.json` จึงยังเป็นหนึ่งสถานะต่อรายงานต่อโฟลเดอร์ได้ แม้รอบเดียวจะเติมหลายวัน (เพิ่ม 2026-10-14) · **ภาพปิดงวด**เป็นภาพของ*งวด* จึงอยู่ในโฟลเดอร์ของวันสุดท้ายของงวด (เช่น 2026-09-30) ไม่ใช่วันที่ถ่าย
บันทึกใน `_run.json` ด้วย id `<รายงาน>@period-close` แยกจากภาพปกติของวันนั้น และถ่ายได้แค่ 7 วันแรกของงวดถัดไป — พ้นแล้วไม่ใช่ภาพปิดงวด (ใบ 05)
