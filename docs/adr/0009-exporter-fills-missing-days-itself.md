# exporter หาและเติมวันที่ขาดเองจากที่เก็บข้อมูล ไม่ใช้คิวของ Windmill

2026-10-13 · เมื่อรอบรายวันดึงวันเดียว (ADR-0008) การพลาดรอบไม่มีช่วงคร่อมมาบังอีก วันที่ขาดจะเป็นรูถาวรถ้าไม่มี
ใครเติม · **ทางที่เลือก:** ทุกรอบ (รอบรายวัน รอบเก็บตก และการกดปุ่มของพนักงาน FoodStory) ดูที่เก็บข้อมูลว่ามี
**วันของข้อมูล** ไหนตั้งแต่ **วันเริ่มใช้งาน** ที่ถึงกำหนดแล้วแต่ยังไม่มีข้อมูลหรือยังไม่ **ว่าง** แล้วดึงทุกวันนั้นในรอบ
เดียว จำกัดจำนวนวันต่อรอบ เกินนั้นแจ้งเตือนแทน (เดิมตั้ง 14 วัน — วัดจริง 2026-10-14 แล้วเกิน timeout 15 นาทีของ job บน Windmill
จึงลดเป็น 3 วัน ≈ 10 นาทีรวมรายงาน snapshot ดู `CATCH_UP_CAP_DAYS`) · Windmill เป็นแค่ตัวปลุกตามเวลาเหมือนเดิม · มี `--date` ให้คนสั่งวัน
เดียวเอง

**ทางที่ไม่เลือก:** ให้ Windmill ตรวจแล้วแตกเป็นงานต่อวันเข้าคิว — ความจริงจะอยู่สองที่ (ที่เก็บข้อมูลกับคิว) ใช้กับ
ปุ่มของพนักงาน FoodStory ไม่ได้เพราะไม่ได้รันผ่าน Windmill และย้ายเครื่องต้องย้ายตรรกะใน Windmill ไปด้วย

**ผลที่ตามมา:** แทนข้อ "ไม่ไล่เก็บวันที่พลาด" ของ ADR-0006 — การกด captcha ครั้งเดียวเติมวันที่พนักงานไม่ได้กดได้
หลายวัน (รายงาน snapshot ของวันที่ไม่ได้กดยังหายถาวร) · ที่เก็บข้อมูลต้องแยกสถานะ มีข้อมูล / ว่าง / ล้ม / ยังไม่ได้ดึง
ได้ชัด เพราะเป็นตัวตัดสินว่าวันไหนต้องเติม
