# หน้าที่ไม่มีปุ่ม export (Audit trail) ส่งเป็นไฟล์ดิบแบบ scrape — ข้อยกเว้นเดียวของ ADR-0007

2026-11-14 · recon ความสมบูรณ์ของข้อมูล in-house (ADR-0011 ต่อเนื่อง) พบว่า snapshot บอกได้แค่สถานะ ณ ตอนถ่าย — ย้อนวันไม่ได้ประวัติ (หน้า in-house/arrivals/
departures ตอบเป็นสถานะ**ปัจจุบัน**กรองด้วยวัน คนที่ออกไปแล้วหาย) และโรงแรมเช็คอินได้ทั้งวัน การจองแล้วเข้าพักทันทีก็มี · แหล่งที่ครบคือ **Audit trail**:
ทุกเหตุการณ์พร้อมเวลาระดับวินาที (check-in/out = `Room status change` + `Status: …`, ห้อง 505 ตรง handoff: ย้ายห้อง 10:14:49 / check-in 14:15:51) วันละ 104–168 แถว
ไม่ชนเพดาน 500 · แต่หน้านี้**ไม่มีปุ่ม export** (`specs/07`)

**ทางที่เลือก:** อ่านตาราง `dtgList` จากหน้าเว็บแล้วเขียนเป็น **ไฟล์ดิบแบบ scrape** (CSV UTF-8) — เซลล์ทุกช่องตามข้อความบนหน้าเว็บทุกตัวอักษร (วันที่คง `DD/MM/YYYY HH:MM:SS`
ไม่ตัด ไม่กรองแถว รวมแถว login ซึ่งมีชื่อผู้ใช้ระบบ — ตาม ADR-0007 ที่ uploader เป็นเจ้าของการกำกับดูแลข้อมูลส่วนบุคคล) · manifest ระบุ `source: scrape` ให้ uploader รู้ว่า
ไม่ใช่ไบต์ของ Site · รายงานตามวัน (ADR-0008): วัน D ดึงรอบเที่ยง D+1 ไฟล์ละวัน เติมวันที่ขาดเองตาม ADR-0009 · ไม่ถ่ายระหว่างวัน (ความสดของวันนี้ยังเป็นหน้าที่ของ snapshot ADR-0011)
· exporter ไม่ตีความเหตุการณ์ — ส่งครบทุกแถว การแยก Stay event และสร้างช่วงเข้าพักเป็นงานของ `hoteltime-schema`
· ขอปุ่ม export/API จาก HotelTime คู่ขนาน (`specs/07` ข้อ D) — ถ้าได้ ใช้ไฟล์จริงแทนโดยไม่กระทบ consumer

**ทางที่ไม่เลือก:** เก็บ HTML ของตารางเป็นไฟล์ดิบ (ใกล้ความจริงกว่า แต่ uploader ต้องมีตัว parse HTML) · กรองแถวเฉพาะ operation ที่เกี่ยวห้อง/การจอง (ตัดสินใจแทนเจ้าของข้อมูล และ ADR-0007
ปฏิเสธการตัดข้อมูลก่อนส่งไว้แล้ว) · ถ่าย audit ซ้ำรอบ 18:00 (ให้ข้อมูลเท่า snapshot ที่มี — เพิ่มทีหลังได้ด้วยกลไกของ ADR-0011)

**ผลที่ตามมา:** ข้อยกเว้นนี้จำกัดอยู่ที่หน้าที่ไม่มี export จริง ๆ — ไฟล์ที่เรา**เขียน**เองจึงมีความเสี่ยงที่ไฟล์ที่ Site ให้ไม่มี (อ่านตารางผิด/ตกแถว) ต้องมีด่านตรวจเข้มกว่า
(หัว 9 คอลัมน์ตรงเป๊ะ, ไม่ชนเพดาน 500 — ถ้าชนแบ่งช่วงเวลาแล้วรวม, วันที่ไม่มีแถวเลย = **ล้ม** ไม่ใช่ "ว่าง" เพราะระบบที่ใช้งานอยู่มี login ทุกวัน) ·
**ยืนยันไม่ได้ตอนเขียน:** uploader รับ CSV + document_type `hoteltime_audit_trail` หรือไม่ (ไฟล์ที่ document_type ไม่อยู่ใน catalog ถูกปฏิเสธไม่ส่ง ไม่เดา — ปลอดภัยจนกว่าทีมนั้นตอบ)
· ภาคผนวก: ตัวอ่านตารางต้องทดสอบด้วยหน้าจริงเป็นครั้ง ๆ (ไม่อยู่ใน CI) เหมือนด่านอื่นของ Playwright
